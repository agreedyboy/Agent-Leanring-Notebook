# Learner Profile

This document describes the project owner's current learning profile for RAG testing.

The project owner is a computer science undergraduate who is learning LLM agent engineering through a staged project roadmap. The current focus is building a document-grounded RAG research agent after completing a minimal agent harness.

The owner's technical interests include agent loops, tool calling, function calling, tracing, evaluation, retrieval augmented generation, citation verification, and practical AI engineering for internships.

The owner has already built an Agent Harness Mini project with a command line interface, JSONL tracing, session state, context window management, tool registry, and fixed evaluation cases.

The current project goal is to build a RAG research agent that can ingest local documents, split them into chunks, create embeddings, retrieve relevant chunks, answer questions with citations, and avoid unsupported answers.

The owner's preferred learning style is implementation-first: read a small amount of focused material, build a minimal working system, test it, record failure cases, and then improve the system step by step.
